# ADR 0001：公开只读站点不启用入口认证

- 状态：已接受
- 日期：2026-08-25

## 背景

本项目是六维信用体系的公开展示入口，不包含用户账户、管理后台、写操作或
私有 API。模板默认的 Caddy Basic Auth 会阻止公众直接访问，也不符合内容
传播目标。

## 决策

移除 Caddy Basic Auth 及其环境变量，允许公众直接访问页面。
Next.js 的 `3000` 端口仍只在 Docker 私有网络暴露，对公网仅开放 Caddy 的
`80/443`。Caddy 继续负责自动 HTTPS、反向代理和安全响应头。

只有主展示页、时代人物对照表和页面所需图片进入 `public/`。原始 Markdown
母版和其他内部资料不进入 Git 或生产镜像。

## 备选方案

- 保留 Basic Auth：安全边界更强，但与公开传播目标冲突。
- 建立正式用户认证：当前没有个性化数据或受限功能，成本没有业务收益。

## 影响

所有获得网址的人都能查看公开页面。后续若增加后台、写操作、个人数据或
付费内容，必须为对应路由引入正式认证与授权，不能依赖页面链接隐藏。

## 回滚

在 Caddy 中恢复受保护路由，并重新加入经过哈希处理的认证环境变量；部署后
验证公开页面返回 `401`，健康检查仍可供容器使用。
